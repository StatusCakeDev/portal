Installation

Installation of each StatusCake API SDK should be performed through the respective package manager, or directly from GitHub where appropriate. This guide will prefer the use of a dependency manager unless otherwise stated.

Use the following steps to install the StatusCake API SDK for the desired language:

info

Some SDKs are currently in alpha and will not be given support at this time. We are currently working to deliver stable releases for each of these projects. Read more about alpha releases in the documentation.

  • Go
  • JavaScript (alpha)
  • Python (alpha)
  • Ruby (alpha)
Install statuscake-go
go get github.com/StatusCakeDev/statuscake-go
Install statuscake-js
npm install -D statuscake-js
Install statuscake-py
pip install statuscake-py
Install statuscake-rb
bundle add statuscake-rb

Requirements​

  • Go
  • JavaScript (alpha)
  • Python (alpha)
  • Ruby (alpha)

The Go SDK supports the three latest major releases of Go. It is a Go module, so importing it is enough for the toolchain to fetch it:

Import the SDK
import "github.com/StatusCakeDev/statuscake-go"

Its only dependencies are in the standard library.

See the statuscake-js repository for the supported versions of Node.js.

See the statuscake-py repository for the supported versions of Python.

See the statuscake-rb repository for the supported versions of Ruby.

Pinning a version​

Add the SDK at a specific version in the same way as any other dependency, and upgrade deliberately. Go modules record the version in go.mod, which you should commit:

Install a specific version
go get github.com/StatusCakeDev/statuscake-go@vX.Y.Z

Read the release notes on GitHub before upgrading, particularly for SDKs that are still in alpha.
