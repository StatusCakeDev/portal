StatusCake is a website monitoring platform with a focus on providing
observability for the applications you maintain. Here you will find developer
documentation to help integrate StatusCake into your own monitoring suites.

Create an [uptime check](https://app.statuscake.com/AddSite.php) or use our API
to automate your experience.

## Choose a tool

There are several ways to work with StatusCake programmatically. Which suits you
depends on what you are doing.

| If you want to | Use |
| --- | --- |
| Build StatusCake into your own software | The [Go SDK](/guides/sdks/introduction), or the [API](/guides/api/introduction) directly |
| Keep your monitoring in version control alongside your infrastructure | The [Terraform provider](/guides/terraform/introduction) |
